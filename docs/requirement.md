# 需求文档（Audio Engine + 虚拟声卡分离方案）

**项目名称：** 跨平台实时音频处理引擎（支持 AI 同声传译）

**版本：** 0.1

## 目标

- 构建一个可替换虚拟声卡的音频引擎
- 当前阶段使用第三方虚拟声卡（VB-Cable / BlackHole）
- 提供统一跨平台的音频 I/O 接口
- 支持实时音频流采集、处理、输出
- 未来可平滑替换自研虚拟声卡驱动

## 1. 功能需求

| 功能          | 描述                       | 当前实现                | 终态                    |
|--------------|---------------------------|------------------------|------------------------|
| 虚拟声卡接入  | 从系统虚拟声卡获取输入      | VB-Cable / BlackHole   | 自研虚拟声卡            |
| 系统设备输出  | 输出处理后的音频            | 系统扬声器 / 耳机       | 系统扬声器 / 耳机       |
| 音频处理      | AI 同声传译 / DSP          | DummyEngine（直通）    | AI / DSP 引擎          |
| 统一音频接口  | Input/Output 抽象          | PortAudio Adapter      | 自研 Adapter 可替换     |
| 多平台支持    | Windows / macOS / Linux   | ✅                     | ✅                     |
| 用户配置      | 可选择输入/输出设备         | GUI / CLI              | GUI / CLI / 自动检测    |
| 采样率 & buffer | 固定 48kHz / 128 frames | ✅                     | ✅                     |

## 2. 非功能需求

| 属性      | 描述                                         |
|-----------|---------------------------------------------|
| 实时性    | 输入 → AI → 输出延迟 < 200ms（可优化）        |
| 可维护性  | 业务代码与 I/O 实现分离，未来可替换虚拟声卡    |
| 可扩展性  | 支持多语言、多通道、多输出                     |
| 安全性    | AudioThread 无动态分配，无阻塞操作             |
| 稳定性    | 支持长时间运行 (>24h) 不崩溃                  |

## 3. 技术选型

| 模块          | 技术/框架                      | 说明                                |
|--------------|-------------------------------|-------------------------------------|
| 音频 I/O     | PortAudio                     | 当前跨平台实现，RT-safe，可替换      |
| AI / DSP     | C++ / ONNX Runtime / CUDA     | 后端推理处理                        |
| 未来虚拟声卡  | 自研 Driver                   | macOS Audio HAL / Windows KS       |
| 编译工具链    | CMake / C++17                | 跨平台构建                          |
| 日志与监控    | spdlog / 日志文件             | AudioEngine 状态追踪                |

## 4. 阶段计划

### 阶段 1（当前）

- PortAudio + VB-Cable / BlackHole
- AI 引擎占位（DummyEngine）
- 构建可编译 Demo

### 阶段 2（优化）

- 多线程 RT-safe 音频管线
- 延迟测量与优化
- 支持多虚拟设备路由

### 阶段 3（终态）

- 自研虚拟声卡
- 系统 Adapter 替换
- AI 引擎正式上线
