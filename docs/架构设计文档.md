# 架构设计文档（PortAudio + 可替换虚拟声卡）

## 1. 架构概览

```
┌─────────────────────────┐
│      应用层 / UI         │
│  - 设备选择              │
│  - 状态监控              │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│   Audio Engine Core     │
│  - AudioPipeline        │
│  - RingBuffer / Queue   │
│  - DSP / AI Engine      │
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  Audio I/O Adapter      │
│ (Platform Abstraction)  │
│  - PortAudio Adapter    │  ← 当前阶段
│  - VirtualAdapter       │  ← 未来阶段
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│ 系统音频设备 / 驱动      │
│  - VB-Cable / BlackHole │
│  - 系统扬声器 / KS / CoreAudio │
└─────────────────────────┘
```

## 2. 模块说明

### 2.1 AudioEngine Core

**功能：**

- 管理音频管线（Input → AI/DSP → Output）
- 多线程缓冲（输入线程 / AI 线程 / 输出线程）
- 保证 RT-safe

**接口：**

- `IAudioInput`, `IAudioOutput`

**数据流：**

- PCM float 32bit
- 固定采样率 48kHz，固定帧长 128

### 2.2 Audio I/O Adapter

**功能：**

- 抽象系统设备和虚拟声卡
- 封装 PortAudio 设备枚举 / 打开 / 读写
- 未来可替换为自研虚拟声卡 Adapter

**当前实现：**

- `PortAudioInput`, `PortAudioOutput`

**未来实现：**

- `VirtualAudioInput`, `VirtualAudioOutput`

### 2.3 系统音频设备

**作用：**

- 提供音频源（虚拟或物理）
- 提供音频输出（扬声器 / 耳机）

**当前方案：**

- VB-Cable / BlackHole

**终态方案：**

- 自研驱动（支持多通道 / 多客户端）

## 3. 音频数据流

```
Input Device (VB-Cable / BlackHole)
    │ read()
    ▼
PortAudio Adapter
    │
    ▼
AudioPipeline
    ├─ RingBuffer
    ├─ DummyEngine / AI
    └─ RingBuffer
    │
    ▼
PortAudio Adapter
    │ write()
    ▼
Output Device (Speaker / Headset)
```

**关键特性：**

- 所有模块之间使用 Lock-free RingBuffer
- AI/DSP 独立线程，保证低延迟
- Adapter 层对外只提供 `IAudioInput` / `IAudioOutput` 接口

## 4. 多平台策略

| 平台    | 当前 Adapter                       | 终态 Adapter                          |
|---------|-----------------------------------|--------------------------------------|
| macOS   | PortAudio (CoreAudio backend)     | Audio HAL Plugin / VirtualAudioAdapter |
| Windows | PortAudio (WASAPI backend)        | KS / WDM / VirtualAudioAdapter       |
| Linux   | PortAudio (ALSA / Pulse / JACK)   | PipeWire / VirtualAudioAdapter       |

**设计原则：**

- PortAudio 统一 API，业务代码无差异
- 未来替换 Adapter 时，业务层无需修改

## 5. 替换虚拟声卡策略

业务层只依赖 `IAudioInput` / `IAudioOutput`

**当前阶段：**

- Adapter = PortAudio + 系统设备 / 第三方虚拟声卡

**未来阶段：**

- Adapter = 自研虚拟声卡 Driver
- 业务层无感知

**迁移步骤：**

1. 开发虚拟声卡 Driver
2. 实现 `VirtualAudioInput` / `VirtualAudioOutput`
3. 替换 Adapter 实例
4. 验证延迟与稳定性

## 6. 技术要点

- 所有音频处理线程 RT-safe
- Buffer size / Sample rate 固定
- 未来 Driver Adapter 与 Engine 之间保持清晰接口
- 用户可以配置输入 / 输出设备（GUI 或 CLI）
